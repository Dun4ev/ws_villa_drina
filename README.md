# Vila Mirava и Vila Borika: портфолио-концепты

Два самостоятельных дизайн-концепта сайтов вымышленных вилл. Иллюстративные изображения созданы встроенным image_gen по текстовым описаниям. Сохранены характер виллы с бассейном у реки и деревянного горного дома; это новые сцены, а не фотографии реальных объектов. Это работа для портфолио, не клиентский заказ. React + TypeScript + Vite; SR/EN, галереи, условная планировка, доступные диалоги и мобильная навигация.

Реальные телефоны, email, аккаунты владельцев, точные локации, карты, Booking и YouTube исключены из интерфейса и клиентского кода. Кнопки ведут к галереям или пояснению о концепте. Исходные фото и сведения об их происхождении сохранены. Названия технических файлов и маршрут `/idila/` сохранены для совместимости.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```sh
cd site
npm ci
npm run dev -- --host 127.0.0.1 --port 4175 --strictPort
```

Открыть http://127.0.0.1:4175/. Для английского: `?lang=en`, для сербского: `?lang=sr`. При отсутствии параметра используется сохраненный выбор, затем SR.

## Проверки

```sh
cd site
npm run typecheck
npm run build
npm run test:sites
```

Сборка: `site/dist/client`. Встроенный шаблон также создает Sites worker и metadata; эти артефакты не означают публикацию. Текущая проверка портфолио: `site/portfolio-qa.md`. Историческая проверка дизайна: `site/design-qa.md`.

## Где менять

- `site/src/data/villa.ts`: двуязычные тексты концепта и характеристики для демонстрации.
- `site/src/data/photos.ts`: порядок фотографий, категории, подписи SR/EN.
- `site/src/App.tsx` и `site/src/styles.css`: секции и визуальная система.
- `site/src/components/`: галерея и доступные диалоги.
- `site/asset-manifest.json`: состав новых публичных изображений, размеры и контрольные суммы. `site/generated-assets-prompts.json`: точные промпты. Прежние публичные изображения сохранены в `references/private-archive/public-images-2026-10-18/`; `photo/` и остальные референсы не изменены.
- `DESIGN.md`: согласованные визуальные решения. `site/CONTENT-SOURCES.md`: подтверждения и ограничения контента.

Vila Borika доступна по `/idila/`: отдельная страница `site/src/IdilaPage.tsx`, стили `site/src/idila.css`, новые изображения в `site/public/images/borika/`. Изображения Mirava находятся в `site/public/images/mirava/`. Переходы между объектами находятся в верхнем меню и сохраняют SR/EN. Старые источники сохранены как история в `site/idila-asset-sources.md`. Собственный календарь, платежи, backend и формы отправки не реализованы.

## Публикация

Пользователь разрешил публикацию в GitHub и Cloudflare Pages 2026-10-18. Целевая конфигурация Pages: проект `vila-mirava-borika`, GitHub `Dun4ev/ws_villa_drina`, ветка `main`, корень `site`, команда `npm run typecheck && npm run build && npm run test:sites`, выход `dist/client`, Node.js 22. Переменные production: `CONTEXT=production`, `URL=https://vila-mirava-borika.pages.dev` для абсолютных social URL. Push в `main` запускает новую сборку.

Mirava: `https://vila-mirava-borika.pages.dev/`; Borika: `https://vila-mirava-borika.pages.dev/idila/`. Фактический статус публикации и проверки указан в `site/portfolio-qa.md`.

Прежний Netlify-проект закрыт входом команды для всех деплоев. Сохранен `noindex, nofollow`. Планировка нарисована заново как условная схема вымышленного дома, не в масштабе; изображения не подтверждают характеристики реального объекта. Сборка публикует только `site/dist/client`, а не корень репозитория или архив референсов. Уже существовавшие в Git исходные фото и история сохраняются; локальные архивы и промежуточные PNG исключены из новых коммитов.

Git инициализирован в корне. Зависимости, `.env`, сборка и системные файлы исключены через `.gitignore`.

## Деликатные эффекты

Паттерн [Blur Fade на 21st.dev](https://21st.dev/@dillionverma/components/blur-fade) адаптирован без дополнительной библиотеки. Настройки: `site/src/hooks/useLuxuryMotion.ts` и `site/src/motion.css`. Разметка `data-reveal` отмечает блоки, `data-reveal-delay` задает задержку в миллисекундах. Кнопки бронирования и навигация доступны сразу. Системная настройка уменьшения движения отключает эффекты.
