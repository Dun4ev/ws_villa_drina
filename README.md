# Drina Lux

Адаптивное локальное демо сайта виллы на Дрине. React + TypeScript + Vite; SR/EN, галерея, предварительная планировка, контакты и переход на Booking.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```sh
cd site
npm ci
npm run dev -- --host 127.0.0.1 --port 4175 --strictPort
```

Открыть http://127.0.0.1:4175/. Для английского: `?lang=en`, для сербского: `?lang=sr`. При отсутствии параметра используется сохраненный выбор, затем SR.

## Проверки

```sh
cd site
npm run typecheck
npm run build
npm run test:sites
```

Сборка: `site/dist/client`. Встроенный шаблон также создает Sites worker и metadata; эти артефакты не означают публикацию. Отчет о ручной проверке: `site/design-qa.md`.

## Где менять

- `site/src/data/villa.ts`: двуязычные тексты, характеристики, Booking, телефон, email, Instagram и Google Maps.
- `site/src/data/photos.ts`: порядок фотографий, категории, подписи SR/EN.
- `site/src/App.tsx` и `site/src/styles.css`: секции и визуальная система.
- `site/src/components/`: галерея и доступные диалоги.
- `site/asset-manifest.json`: связь подготовленных изображений с оригиналами. `photo/` и `references/` хранят оригиналы.
- `DESIGN.md`: согласованные визуальные решения. `site/CONTENT-SOURCES.md`: подтверждения и ограничения контента.

Вторая вилла добавляется отдельной записью данных и использует существующие компоненты галереи/контактов. Пока данных нет, карточка не выводится. Собственный календарь, платежи, backend и формы отправки не реализованы.

## Перед публикацией

Подтвердить планировку и площади комнат, проверить условия проживания с владельцем, выполнить редактуру перевода носителем сербского. Сайт сейчас содержит `noindex, nofollow`: после отдельного решения о публикации настроить домен, metadata, индексацию и выполнить проверку опубликованной версии.

Git инициализирован в корне, ветка `main`. Зависимости, `.env`, сборка и системные файлы исключены через `.gitignore`. Первый коммит и удаленный репозиторий пока не созданы.
