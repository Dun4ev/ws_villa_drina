# Drina Lux: дизайн первой версии

Решения согласованы 21 сентября 2026 года.

- Формат: демо бренда с одной полноценной виллой. Второй объект пока не показывать.
- Основной визуальный источник: `references/ChatGPT Image 21 сент. 2026 г., 22_59_14 (2).png`. Первый макет помогает подаче характеристик. Это адаптация визуального языка, не точная копия всех блоков и демонстрационного контента.
- Пользовательский сценарий: познакомиться с виллой, посмотреть фотографии и предварительный план, перейти на Booking либо связаться с владельцем.
- Языки: сербская латиница и английский. SR по умолчанию, выбор сохраняется локально; `?lang=en` / `?lang=sr` дает прямую ссылку на нужный язык.
- Палитра: фон `#F7F5EF`, зеленый `#18332E`, текст `#202A26`, приглушенный `#5A635D`. Прямоугольные кнопки, тонкие линии, без декоративных карточек и тяжелых эффектов.
- Типографика: локальные variable Cormorant Garamond для заголовков и Manrope для текста; заголовки с обычным и курсивным начертанием.
- Фотографии: реальные исходники из `photo/`. Сгенерированные изображения из макетов не являются доказательством характеристик виллы.
- Иконки: Phosphor, тонкое начертание. Основные секции: первый экран и знакомство с виллой. Галерея компактная с фильтрами и увеличением.
- Мобильный сценарий: простое раскрывающееся меню, два действия снизу, большие области нажатия, native dialog для фото/контактов/плана, возврат фокуса и Escape.
- Движение: только короткие переходы и плавная прокрутка; при reduced motion отключаются.
- 21st.dev: не используется как зависимость. Два пользовательских макета достаточно точно задают направление.
